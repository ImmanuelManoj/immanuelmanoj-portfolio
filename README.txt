IMMANUEL MANOJ — PORTFOLIO WEBSITE

Files:
- index.html — complete responsive portfolio website.

How to use:
1. Open index.html in any modern browser.
2. Replace YOUR_EMAIL@example.com with your email.
3. Replace YOUR_NUMBER in the WhatsApp link with your international number, without + or spaces.
4. Replace the Instagram, LinkedIn and YouTube # links with your real profiles.
5. Replace the four project cards with your actual images/videos if desired.

The site is a single-file website: no build tools or framework are required.
